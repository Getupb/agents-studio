# 微信渠道

微信渠道来自 dsh-pet，不是本仓库自己实现的协议。本仓库只做三件事：

1. 把微信渠道的工具集纳入「默认模式」的配置；
2. 允许按渠道做「只做减法」的裁剪；
3. 在微信里增加「正在输入中」状态。

## 前提

- 已安装 dsh-pet `0.4.7`；
- 已运行 `patches/dsh-pet/patch-session-share.mjs`，让微信和工作台页面复用同一间会话，避免写句柄冲突；
- 已运行 `patches/dsh-pet/patch-pet-channel.mjs`（只有需要按渠道裁剪时才必须）；
- 手机微信可以扫码登录。

## 配置

在「设置 → Agent 预设 → 微信渠道」里选择：

- **与主会话相同（推荐）**：微信挂 `default`，能力与工作台完全一致；
- **自定义微信渠道能力（只做减法）**：生成内部变体 `default-wechat`，只少工具，不加工具。

保存后需要重启工作台。重启会同时刷新桌宠进程，微信下次建立会话时使用新配置。

## 为什么不是「另一个模式」

`default-wechat` 不会出现在设置页的模式选择里，也不作为新会话默认。它只是渠道内部变体，目的是让微信在需要时少掉一部分能力；界面仍然只有一个「默认模式」。

## 已知限制

- 微信登录态保存在 `.dsh-home/`，不要提交或分享；
- 微信通道的能力受上游 dsh-pet 限制；
- 图片/文件收发的稳定性依赖上游版本，本项目冻结在 `0.4.7`；
- 不要把 3099 端口暴露到公网。
